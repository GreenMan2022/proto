# ПРОТО — редактор разводки макетной платы

**ПРОТО** — бесплатный браузерный редактор для планирования разводки макетных плат с шагом 2.54 мм. Он помогает быстро разметить отверстия, нарисовать дорожки, обозначить компоненты и подготовить макет к сборке.

Приложение работает полностью в браузере, без установки и регистрации. Проекты и библиотека компонентов сохраняются локально.

## Возможности

- Плата с настраиваемым числом столбцов и рядов, шаг сетки 2.54 мм
- Пины и переходные отверстия с автоматической нумерацией
- Дорожки на лицевой и обратной стороне
- Перемычки отдельным стилем линии
- Контурные рамки и подписи компонентов
- Выделение, перемещение, копирование, вставка, поворот и удаление объектов
- Отмена и повтор действий
- Автоматическая рамка по содержимому схемы
- Подгонка размера платы под выбранную рамку
- Библиотека компонентов: сохранение, вставка, переименование, удаление
- Импорт и экспорт библиотеки в формате JSON
- Сохранение компонентов в выбранную локальную папку
- Открытие и сохранение проектов в JSON
- Автосохранение текущего проекта в браузере
- Экспорт разводки в SVG и PNG
- Печать макета
- Готовый демонстрационный пример

## Инструменты

| Инструмент | Назначение |
|---|---|
| Пин | Установка и удаление пинов |
| Переход | Установка и удаление переходных отверстий |
| Дорожка | Рисование соединений |
| Контур | Создание рамки компонента |
| Стереть | Удаление пинов, дорожек и контуров |
| Выбор | Выделение, перемещение и редактирование объектов |
| Панорама | Перемещение по плате |

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `P` | Пин |
| `T` | Переходное отверстие |
| `W` | Дорожка |
| `O` | Контур |
| `E` | Стереть |
| `V` | Выбор |
| `H` | Панорама |
| `R` | Поворот по часовой стрелке |
| `Shift + R` | Поворот против часовой стрелки |
| `Tab` | Смена направления угла дорожки |
| `Ctrl + Z` | Отмена |
| `Ctrl + Y` | Повтор |
| `Ctrl + C` | Копировать |
| `Ctrl + V` | Вставить |
| `Esc` | Отмена текущего действия |

## Как начать

1. Откройте `index.html` в браузере.
2. Задайте размер платы в поле **Плата**.
3. Выберите инструмент **Пин** и расставьте выводы компонентов.
4. Инструментом **Дорожка** соедините нужные точки.
5. При необходимости добавьте переходные отверстия и дорожки обратной стороны.
6. Сохраните проект или экспортируйте SVG/PNG.

## Формат проекта

Проект хранится в JSON и содержит размеры платы, пины, переходные отверстия, дорожки и контуры компонентов.

Библиотека компонентов также сохраняется в JSON. Каждый компонент может включать пины, контуры, дорожки, подписи и цвета.

## Запуск

Скачайте репозиторий и откройте `index.html` в современном браузере.

Для работы с локальной папкой компонентов рекомендуется Chrome, Edge или другой браузер с поддержкой File System Access API.
